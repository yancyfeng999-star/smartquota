# 智额 0.3.2 (build 5)

- **日期**：2026-08-04
- **标签**：`v0.3.2`

## 本版要点

- 产品全量更名：**智额 · SmartQuota**（Bundle ID `com.smartquota.app`）
- **安全加固**：移除 Sparkle 远程更新；收紧 entitlements；扩展脚本不得逃逸目录；Web/健康检查仅 http(s)
- 配置目录：`~/.smartquota`（兼容迁移早期本机试验配置）
- 详见 `SECURITY.md`

## 安装包

| 文件 | 怎么用 |
|------|--------|
| **智额-0.3.2.dmg** | 打开后，把 App **拖到 Applications**（推荐） |
| **智额-0.3.2.pkg** | 双击，按安装向导装到「应用程序」 |

## 首次打开

若提示无法验证开发者：Control + 点击 → 打开。  
临时签名（ad-hoc）。其他 Mac 首次打开：右键 → 打开，或系统设置 → 隐私与安全性 → 仍要打开。

## 系统

macOS 15.0 或更高。
