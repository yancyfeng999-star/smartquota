# 智额 0.3.19 (build 22)

- **日期**：2026-08-09

## 本版修复

- **ChatGPT 积分 0 不再误标「用尽」**  
  周额度（7D / GPT-5.3 周）重置为 100 后，右上角状态恢复正常。  
  **积分**是可选加油包余额，为 0 时只显示数字，不驱动整卡「用尽」。

## 状态徽章说明

| 徽章 | 含义 |
|------|------|
| 充足 / 正常 | 限速额度（5H / 7D / 周桶）健康 |
| 用尽 | **限速额度**用尽（不是积分 = 0） |

## 已装旧版

设置 → **检查更新** → 下载 dmg → 拖到 Applications 覆盖后重新打开。

## 首次打开

若提示无法验证开发者：Control + 点击 → 打开。
