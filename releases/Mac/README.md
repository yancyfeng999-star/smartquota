## 打包

    ./scripts/package-release.sh

## 使用方式（与常见 Mac 安装包相同）

1. 打开 **.dmg**
2. 将 **智额.app** 拖到 **Applications**
3. 从启动台打开「智额」

或双击 **.pkg** 使用系统安装向导。
