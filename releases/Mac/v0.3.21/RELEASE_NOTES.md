## 本版变更

- **一键更新（PKG 静默安装）**  
  设置 → **检查更新** 发现新版后：优先下载 `.pkg`，**无二次确认弹窗**，静默覆盖安装并自动重启。  
  不打开系统 Installer.app；若目标目录无写权限，可能出现**系统**密码框。  
  若 Release 仅有 dmg，仍打开 dmg（需拖到应用程序）。
