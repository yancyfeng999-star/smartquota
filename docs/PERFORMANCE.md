# 智额 · 资源占用说明

目标：菜单栏常驻时 **低 CPU、低内存、少写盘**。

## 已做优化（0.3.4 起）

| 项 | 策略 |
|----|------|
| 后台刷新默认 | **关闭**；开启后默认 **15 分钟**（不再推荐 1 分钟） |
| 后台刷新范围 | 仅菜单栏相关 provider，非「全会员扫一遍」 |
| 打开菜单刷新 | 最多 **2 路并发**；**45 秒内**已刷新过的跳过 |
| 电池 | 后台间隔自动 ×2 |
| 显示器休眠 | 暂停探测，唤醒后再刷 |
| 文件日志 | 仅 **warning/error** 落盘；上限 **1MB** + 一份滚动 |
| info/debug | 只进系统 OSLog，不刷硬盘 |

## 用户可调

设置 → 后台同步 / 刷新间隔：

- **关闭**：最省（只在打开菜单时更新）  
- **15 / 30 分钟**：推荐常开后台  
- 关闭不用的会员开关：少探测、少网络  

## 预期体感

- 空闲：接近 0% CPU，内存通常几十 MB 量级（SwiftUI + 菜单栏）  
- 打开菜单：短暂 CPU 上升（探测），随后回落  
- 日志目录：`~/Library/Logs/SmartQuota/` 体积可控  

## 开发注意

- 勿在热路径 `AppLog.info` 打大段 JSON（已不写文件，但仍占 CPU）  
- 新 provider 的 `background` 刷新应跳过重活（日报、截图等）
