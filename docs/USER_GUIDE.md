# 智额 · 用户使用手册

面向日常使用。开发相关见 [DEVELOPER.md](./DEVELOPER.md)。  
下载安装见仓库根 [README.md](../README.md) 与 [DISTRIBUTION.md](./DISTRIBUTION.md)。

应用内 **帮助中心**（菜单栏问号，或设置 → 帮助中心）也可打开本手册、日志、诊断中心和 GitHub Release 页面。

**当前 Mac 版本：0.3.28**

---

## 1. 安装与启动

### 1.1 从 GitHub 安装（推荐）

1. 打开 [GitHub Releases](https://github.com/yancyfeng999-star/smartquota/releases)
2. 下载最新的 **SmartQuota** 安装包（首次安装可用 `.dmg` 或 `.pkg`；应用内更新优先 `.pkg`）
3. 打开 dmg，把 **智额** 拖到 **应用程序**；或双击 `.pkg` 按向导安装  
4. 从启动台打开「智额」  
5. 菜单栏出现仪表盘类图标即表示在运行  

若提示无法打开（Gatekeeper）：

- **Control + 点击** 智额 → **打开** → **打开**  
- 或 **系统设置 → 隐私与安全性 → 仍要打开**  
- 或：

```bash
xattr -cr /Applications/智额.app
open /Applications/智额.app
```

### 1.2 开发者本机构建

```bash
cd Apps/Mac
./scripts/build-test-app.sh    # 桌面调试包
# 或
./scripts/package-release.sh   # 正式 dmg/pkg
```

### 1.3 退出

菜单底栏 **退出**（或电源图标）。  
点面板上的 **×** 只关闭面板，**不会**退出应用——菜单栏图标应仍在。

### 1.4 首次启动

第一次打开会弹出引导窗口（可跳过、可关闭，**不会**因此退出应用）：

1. 说明智额是**本机优先**：设置、备注、缓存和诊断留在这台 Mac，不上传密钥、Cookie、完整邮箱或额度明细  
2. 检查 macOS 版本、架构、目录可否写入、钥匙串和通知权限  
3. 选择第一个会员，并跳到已有的「额度检测配置」  
4. 做一次手动检测，结果会区分成功 / 未登录 / 缺少 CLI 或配置  

跳过或中途关闭后，设置里会出现 **继续引导**。已有安装（已有 `settings.json`）不会再自动弹出。若启动进入**安全模式**，引导不会出现。

## 2. 主界面

### 2.1 会员卡片

每张卡片展示：

- 会员名称、套餐标签、续费信息（若已设置开通日）  
- 状态：充足 / 偏低 / 紧张 / 用尽 / 同步中 等  
- 额度主列：**5H**（约 5 小时窗）、**7D**（约 7 天窗）、**总额**  
  - 部分会员总额由官方接口直接给出  
  - 读不出总额时，可用 **7D + 会员续费日** 估算展示  
  - **Cursor 例外**：左右两根条，标题为「Cursor 模型 / 其他模型」，不展示具体模型名  
- 续费色（黄/绿）**只反映会员续费日远近**，不跟周额度是否将用尽混在一起  

#### 状态徽章看什么？

右上角 **充足 / 用尽** 只看**限速额度**（5H、7D、模型周额度等）里**最差**的一档。

| 项目 | 是否影响「用尽」徽章 |
|------|----------------------|
| 5H / 7D / GPT-5.3 周额度 等限速 | **会** |
| ChatGPT **积分**（加油包余额） | **不会**（余额 0 是常态，只显示数字） |
| 总额（日历估算） | 不参与「限速用尽」语义时以限速表计为准 |

因此：周额度刚重置为 **100/100**、积分仍是 **0** 时，徽章应是**正常**，而不是「用尽」。若仍见旧行为，请升级到 **0.3.20+** 后点刷新。

点击卡片可选中该会员；底栏 **打开后台** 会打开该会员官网/控制台（若有）。

### 2.2 底栏按钮

| 按钮 | 作用 |
|------|------|
| 打开后台 | 打开当前选中会员的网页后台 |
| 设置 | 进入设置页 |
| 退出 | 退出应用 |

### 2.3 固定窗口

需要一边写代码一边看额度时，使用 **固定窗口**（钉在屏幕旁、可滚动），避免菜单栏弹层一点外面就消失。

### 2.4 排序

长按卡片进入 **排序模式**，用右侧箭头调整顺序，点 **完成** 保存。顺序写入本地设置。

### 2.5 空状态

若所有会员都关闭，会提示先到设置里开启会员。

## 3. 设置

### 3.1 外观

浅色 / 深色 / 跟随系统。

### 3.2 语言

支持：

简体中文 · English · 日本語 · 한국어 · Русский · العربية · Français · Deutsch · Español · Português  

切换后 **立即生效**，无需重启。阿拉伯语为从右到左（RTL）布局。

### 3.3 额度显示

百分比按 **剩余** 或 **已用** 展示。

### 3.4 会员开关

- 列表包含全部已注册内置会员（及扩展）。  
- **打开** 后：主菜单出现卡片，且进入下方「额度检测配置」。  
- 可填写：  
  - **套餐**：自行填写展示名（如 Plus / Pro；仅本机保存，不上传）  
  - **开通** 日期：按自然月自动计算下次续费显示（可选，仅本机）  

### 3.5 额度检测配置

- **只显示已开启的会员**。  
- 展开某一会员可查看：  
  - **如何检测**（分步说明）  
  - 探测模式 / API Key 等（视会员而定）  
  - **检测配置**：成功 / 失败状态  

#### 核心四会员配置提示

| 会员 | 你需要准备什么 |
|------|----------------|
| ChatGPT | 本机登录 `codex` 生成 `~/.codex/auth.json`，建议 API 模式 |
| Kimi | 安装 kimi CLI，或配置 sk-kimi / 浏览器 Cookie |
| MiniMax | Coding Plan API Key；区域选国内或国际；视频额度按**条数**展示 |
| Grok | 本机 `grok` / xAI 登录生成 `~/.grok/auth.json` |

扩展会员（Claude、Cursor、Copilot 等）在开关打开后同样出现在此区，按卡片内说明配置。

### 3.6 后台同步

选择自动刷新间隔；选「关闭」则主要在打开菜单时更新。

### 3.7 登录时启动

开机登录后自动启动智额（系统「登录项」）。

### 3.8 日志

右侧 **打开** 按钮：用默认应用打开当前日志文件（`~/Library/Logs/SmartQuota/SmartQuota.log`），便于排查探测失败原因。帮助中心也可打开同一文件。

### 3.8.1 诊断中心

设置中的 **诊断中心** 会检查系统、权限、CLI、凭证、网络和缓存。失败项会区分「未登录 / 缺少 CLI / 缺少 Key / 网络失败 / 服务拒绝 / 缓存过期」，并给出打开配置、帮助、后台、日志或重试。复制摘要只包含版本、系统、架构、检查结果和错误编号，不含密钥或完整邮箱。

### 3.8.2 帮助中心

设置中的 **帮助中心**（或菜单栏问号、⌘?）包含：

- 首次配置、检查更新、日志位置、多账号、密钥安全、隐私、FAQ  
- **打开日志**、**打开诊断中心**、**打开 Release 页面**、**打开本地用户手册**（本文件）

错误说明统一写成三句：**发生了什么**、**是否保留旧数据**、**下一步怎么做**。刷新失败时旧额度快照会保留。

VoiceOver、键盘焦点、动态字体、浅色/深色、减少动画和从右到左语言均可使用：图标按钮有标签；危险操作（删除账号、重置设置、导出）可用键盘确认。

### 3.9 检查更新（Mac）

1. 设置底部找到 **检查更新**，或从帮助中心打开 Release 页面  
2. 应用访问公开的 GitHub Releases（无需登录），默认只看**稳定版**  
3. 若有新版本：先显示当前版本、新版本、发布日期、变更说明、安装包大小和最低 macOS  
4. 只有你在更新区域再点 **下载并安装** 才会下载；系统版本不够时只说明原因，不下载  
5. **优先 PKG**（退出后替换当前 App）。没有 PKG 时回退打开 **DMG**，由你拖到「应用程序」  
6. 缺少合法 PKG/DMG 或校验信息时，显示资产异常，**可打开** Release 页面手动下载，不伪造“已更新”  
7. 安装失败会保留当前可启动的 App；成功替换前不会把界面写成新版本  

当前默认构建是 **临时签名（ad-hoc）**，通常**未公证**。其他 Mac 首次打开：Control-点击 → 打开，或系统设置 → 隐私与安全性 → 仍要打开。只有带 **Developer ID** 的包才是正式签名。

**不会**在后台静默安装或强制更新。

**当前建议最低版本**：ChatGPT 状态相关修复请使用 **0.3.20+**。

### 3.10 关于

显示 **版本号** 与 **构建号**。  
- 版本号：功能版本（如 0.3.20）  
- 构建号：同版本内打包序号（如 22）

## 4. 常见问题

**Q：ChatGPT 周额度已是 100/100，卡片仍显示「用尽」？**  
A：旧版会把 **积分 = 0** 误当成用尽。请升级到 **0.3.20+**（设置 → 检查更新），刷新后徽章应恢复正常。积分是可选加油包，余额 0 不代表限速用尽。

**Q：卡片一直「不可用」或失败？**  
A：到「额度检测配置」点检测；按「如何检测」补齐 CLI 登录或 API Key。查看日志中的具体错误。

**Q：开启了很多会员，菜单很乱？**  
A：关掉不用的会员；或用排序把常用的放前面。新装扩展会员默认是关的。

**Q：换电脑后额度没了？**  
A：额度来自各平台账号与本机凭证。需在新电脑重新登录对应 CLI/客户端，并重新配置 Key（Keychain 不随应用包迁移）。

**Q：隐私？**  
A：探测在本机完成，读本地凭证或访问对应官方 API；应用不提供云端账号体系。请勿分享密钥文件。详见 [SECURITY.md](../SECURITY.md)。

**Q：会自动更新吗？**  
A：**不会静默自动更新**。在设置中点 **检查更新**，阅读说明后再确认下载。应用内优先 **PKG**，没有 PKG 时打开 **DMG**；也可从 GitHub Release 手动下载。默认 ad-hoc 签名，首次打开需右键打开。

**Q：关掉面板后菜单栏图标没了？**  
A：智额是**菜单栏后台应用**（无 Dock 图标）。点 **×** 只关闭面板，图标应还在菜单栏。只有点 **退出** 才会结束进程。若图标消失：从启动台或应用程序再打开一次；可在设置中开启「登录时启动」。

**Q：Grok 续费一直是黄色？**  
A：续费色只看**会员续费日**是否临近。若开通日填得近、或系统按月算出的下次续费临近，会显示黄；与 5H/7D 是否用尽无关。

**Q：MiniMax 视频为什么不是 100/100？**  
A：视频额度按 API 返回的**条数上限**展示（常见 3 条/日），不是百分比套 100。

## 5. 多账号管理

### 5.1 什么是多账号？

智额支持同一会员（如 Codex、Claude）跟踪多个账号。例如：

- 个人账号 `personal@example.com`
- 工作账号 `work@example.com`

**重要说明：**
- 多账号**不等于**托管多份 OAuth 登录
- 只有当前本机登录的账号会刷新额度
- 其他账号保留最后一次成功快照，显示"未登录"
- 历史快照**不参与告警**

### 5.2 添加账号

根据会员类型，添加方式不同：

#### 本机登录型（Codex、Claude、Grok、Gemini、Cursor 等）

1. 在设置中打开对应会员
2. 点击"添加账号"
3. 在外部工具（CLI 或客户端）切换到新账号
4. 回到智额点击"检测当前登录"
5. 智额会识别邮箱或账号 ID
6. 新邮箱会提示确认添加

#### 手动密钥型（MiniMax、Copilot、Z.ai、阿里云 等）

1. 点击"添加账号"
2. 填写邮箱、备注及 API Key/Cookie
3. 智额验证凭证后保存
4. 密钥安全保存到系统钥匙串

#### Profile/路径型（AWS Bedrock、Mistral 等）

1. 点击"添加账号"
2. 选择 AWS Profile 或配置路径
3. 填写邮箱或账号备注
4. 智额保存非敏感配置信息

### 5.3 账号状态

| 状态 | 含义 |
|------|------|
| 已登录 | 当前本机可用，额度实时刷新 |
| 未登录 | 登录态失效，显示最后已知额度 |
| 连接失败 | 网络或服务错误，保留旧快照 |
| 待确认 | 后台发现新邮箱，等待用户确认 |

### 5.4 切换账号

在会员详情页选择要查看的账号。切换只改变显示，不影响后台刷新。

### 5.5 删除账号

1. 在账号管理中选择要删除的账号
2. 确认删除
3. 智额会清理：
   - 该账号的配置信息
   - 该账号的额度快照缓存
   - 该账号的 Keychain 密钥（如有）

**注意：** 删除不会影响外部工具的登录态。

### 5.6 历史快照

- 未登录账号保留最后一次成功刷新的额度
- 快照显示更新时间，方便判断是否过期
- 过期快照仅供参考，不参与告警计算

## 6. 密钥管理与指纹解锁

### 6.1 功能说明

智额支持使用指纹（Touch ID）或面容（Face ID）保护敏感密钥。启用后，访问 API 密钥时需要验证身份。

### 6.2 启用指纹保护

1. 打开智额设置
2. 找到"安全"卡片
3. 点击"管理"进入密钥管理页面
4. 开启"启用指纹保护"开关

### 6.3 使用指纹解锁

1. 点击密钥管理页面
2. 系统弹出指纹验证提示
3. 将手指放在 Touch ID 传感器上
4. 验证成功后即可查看和管理密钥

### 6.4 密码回退

如果指纹验证失败或设备不支持生物识别：

1. 点击"使用密码"按钮
2. 输入系统密码
3. 验证成功后即可访问

### 6.5 支持的设备

| 设备 | 认证方式 |
|------|----------|
| MacBook Pro（带 Touch Bar） | Touch ID |
| MacBook Air（M1/M2/M3） | Touch ID |
| Magic Keyboard（带 Touch ID） | Touch ID |
| 其他 Mac | 系统密码 |

### 6.6 安全说明

- 生物识别模板存储在设备安全芯片中，永不离开设备
- 敏感密钥使用 Keychain 访问控制保护
- 每次访问都需要用户交互验证
- 设备丢失后，密钥无法被他人访问
