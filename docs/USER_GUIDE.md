# 智额 · 用户使用手册

面向日常使用。开发相关见 [DEVELOPER.md](./DEVELOPER.md)。

---

## 1. 安装与启动

1. 使用 `Apps/Mac/scripts/build-test-app.sh` 生成桌面 **`智额.app`**（或由维护者提供安装包）。  
2. 双击启动。菜单栏出现仪表盘类图标即表示在运行。  
3. 测试版会在 Dock 显示图标，便于确认已打开。  
4. 退出：菜单底栏 **退出**（或 Dock 图标右键退出）。

若提示无法打开（Gatekeeper）：

```bash
xattr -cr ~/Desktop/智额.app
```

## 2. 主界面

### 2.1 会员卡片

每张卡片展示：

- 会员名称、套餐标签、续费信息（若已设置开通日）  
- 状态：充足 / 偏低 / 紧张 / 用尽 / 同步中 等  
- 额度条：常见为 **5 小时**、**7 天**、**总额**（部分会员由周额度估算总额）

点击卡片可选中该会员；底栏 **打开后台** 会打开该会员官网/控制台（若有）。

### 2.2 底栏按钮

| 按钮 | 作用 |
|------|------|
| 打开后台 | 打开当前选中会员的网页后台 |
| 设置 | 进入设置页 |
| 退出 | 退出应用 |

### 2.3 固定窗口

需要一边写代码一边看额度时，使用 **固定窗口**（钉在屏幕旁、可滚动），避免菜单栏弹层一点外面就消失。

### 2.4 排序

长按卡片进入 **排序模式**，用右侧箭头调整顺序，点 **完成** 保存。顺序写入本地设置。

### 2.5 空状态

若所有会员都关闭，会提示先到设置里开启会员。

## 3. 设置

### 3.1 外观

浅色 / 深色 / 跟随系统。

### 3.2 语言

支持：

简体中文 · English · 日本語 · 한국어 · Русский · العربية · Français · Deutsch · Español · Português  

切换后 **立即生效**，无需重启。阿拉伯语为从右到左（RTL）布局。

### 3.3 额度显示

百分比按 **剩余** 或 **已用** 展示。

### 3.4 会员开关

- 列表包含全部已注册内置会员（及扩展）。  
- **打开** 后：主菜单出现卡片，且进入下方「额度检测配置」。  
- 可填写：  
  - **套餐**：自行填写展示名（如 Plus / Pro；仅本机保存，不上传）  
  - **开通** 日期：按自然月自动计算下次续费显示（可选，仅本机）  


### 3.5 额度检测配置

- **只显示已开启的会员**。  
- 展开某一会员可查看：  
  - **如何检测**（分步说明）  
  - 探测模式 / API Key 等（视会员而定）  
  - **检测配置**：成功 / 失败状态  

#### 核心四会员配置提示

| 会员 | 你需要准备什么 |
|------|----------------|
| ChatGPT | 本机登录 `codex` 生成 `~/.codex/auth.json`，建议 API 模式 |
| Kimi | 安装 kimi CLI，或配置 sk-kimi / 浏览器 Cookie |
| MiniMax | Coding Plan API Key；区域选国内或国际 |
| Grok | 本机 `grok` / xAI 登录生成 `~/.grok/auth.json` |

扩展会员（Claude、Cursor、Copilot 等）在开关打开后同样出现在此区，按卡片内说明配置。

### 3.6 后台同步

选择自动刷新间隔；选「关闭」则主要在打开菜单时更新。

### 3.7 登录时启动

开机登录后自动启动智额（系统「登录项」）。

### 3.8 日志

右侧 **打开** 按钮：用默认应用打开当前日志文件，便于排查探测失败原因。

### 3.9 关于

显示 **版本号** 与 **构建号**。  
- 版本号：功能版本（如 0.2.0）  
- 构建号：同版本内打包序号（如 2）

## 4. 常见问题

**Q：卡片一直「不可用」或失败？**  
A：到「额度检测配置」点检测；按「如何检测」补齐 CLI 登录或 API Key。查看日志中的具体错误。

**Q：开启了很多会员，菜单很乱？**  
A：关掉不用的会员；或用排序把常用的放前面。新装扩展会员默认是关的。

**Q：换电脑后额度没了？**  
A：额度来自各平台账号与本机凭证。需在新电脑重新登录对应 CLI/客户端，并重新配置 Key（Keychain 不随应用包迁移）。

**Q：隐私？**  
A：探测在本机完成，读本地凭证或访问对应官方 API；应用不提供云端账号体系。请勿分享密钥文件。

**Q：会自动更新吗？**  
A：不会远程自动更新。新版本请从本仓库 Release 或自行构建安装。

**Q：关掉面板后菜单栏图标没了？**  
A：智额是**菜单栏后台应用**（无 Dock 图标）。点 **×** 只关闭面板，图标应还在菜单栏。只有点 **退出 / 电源** 才会结束进程。若图标消失：从启动台或应用程序再打开一次；可在设置中开启「登录时启动」。

## 5. 系统要求

- macOS 15.0 或更高  
- 各会员对应的 CLI 或客户端（按你启用的会员准备）
